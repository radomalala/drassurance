# La Clinique des Résiliés — Démo

Petit projet démo React + TypeScript + TailwindCSS basé sur la maquette fournie.

Prérequis
- Node.js 18+ (ou compatible)

Installer et lancer en local

```powershell
cd d:\Rado\lovable\DrAssurance
npm install
npm run dev
```

Construction et aperçu

```powershell
npm run build
npm run preview
```

Déploiement sur Vercel
- Connecter le dépôt GitHub à Vercel et définir la commande de build `npm run build`.
- Le dossier de sortie est `dist`.

Notes
- Le composant principal est `src/pages/CliniqueResiliesFull.tsx`.
- Tailwind est préconfiguré dans `tailwind.config.cjs`.
